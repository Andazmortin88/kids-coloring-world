# Kids Coloring World

PWA mewarnai anak 3–8 tahun dengan pendamping. Versi ini menambahkan pena, kuas, ketebalan 2–40 px, lima preset garis, palet dan pemilih warna bebas, serta pengisian area tertutup yang mempertahankan warna di bagian lain.

Aplikasi statis berjalan di GitHub Pages dari root repositori. Tidak memerlukan build atau dependensi eksternal. `manifest.webmanifest` memakai jalur relatif agar mendukung `/kids-coloring-world/`. Cache PWA dibatasi pada cakupan aplikasi. Konten gratis 12 sketsa; aktivasi premium memakai kunci publik ECDSA. Kunci penandatanganan dan admin penjual tidak termasuk repositori ini. PDF berbayar juga tidak disertakan.

Profil, progres, dan galeri disimpan di browser. Tidak ada akun/email anak, analytics, iklan, kamera atau mikrofon. Pembelian hanya melalui orang tua. Suara Indonesia memanfaatkan mesin baca perangkat dan dapat tidak tersedia. Gerbang hitung adalah pengingat pendamping, bukan autentikasi kuat.

Memindahkan domain tidak memindahkan penyimpanan browser otomatis. Orang tua dapat membuat cadangan dari versi lama lalu memulihkannya di versi ini. Simpan berkas cadangan secara privat.

## Pemakaian
Pilih sketsa dan warna. Isi area mewarnai satu bidang tertutup. Pena membuat detail, kuas membuat goresan bebas; pilih ketebalan atau geser pengaturnya. Warna dapat diganti setiap bidang/goresan tanpa menghapus warna sebelumnya. Garis pena yang menutup sebuah bidang juga menjadi batas bagi alat Isi area. Undo membatalkan sampai 12 perubahan. Simpan karya menyimpan PNG ke galeri lokal.

Keyboard: fokuskan kanvas, panah untuk berpindah, Enter untuk isi area/titik, Shift+panah untuk garis pena/kuas.
